# Helper in student's life

Telegram-бот для студентов: расписание пар, напоминания, задачи с дедлайнами, заметки и лекции по предметам.

## Что умеет

- **Расписание.** Загрузка текстом, файлом календаря (.ics), Excel (.xlsx) или CSV. Кнопки «Сегодня», «Завтра», «Неделя».
- **Напоминания о парах.** За 15 минут до начала (можно 5, 10, 30, 60 или любое число через `/remind`).
- **Задачи и дедлайны.** `/task Математика: решить №5 до 30.10 18:00`. Напоминание за сутки и за час.
- **Предметы.** Создаются сами из расписания, а свои можно добавить кнопкой «➕ Новый предмет» в «📚 Лекции» или командой `/subject Математика`.
- **Заметки по предметам.** `/note Физика: U = IR`.
- **Лекции.** Пришли боту файл, фото конспекта, голосовое или видео. Подпиши названием предмета, и бот сохранит лекцию в нужную «папку». Без подписи бот спросит предмет кнопками.
- **Часовой пояс.** `/tz Asia/Tashkent`, `/tz Europe/Moscow` и т.д.

## Формат расписания

Текстом, по паре в строке:

```
Пн 09:00-10:30 Математика | ауд. 101 | Иванов И.И.
Пн 10:45-12:15 Физика | ауд. 204
Вторник
09:00-10:30 История
```

Таблицей (Excel или CSV): колонки `день, время, предмет, аудитория, преподаватель` или `день, начало, конец, предмет, аудитория, преподаватель`. Пустой день означает «тот же, что выше». Пример: [example_schedule.csv](example_schedule.csv).

Календарём (.ics), например экспортом из Google Календаря, Outlook или с сайта вуза. Каждое занятие попадает в свой день недели и время, повторы схлопываются в одну пару.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Установи Python 3.11+.
3. В папке проекта:

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env             # впиши BOT_TOKEN в .env
   python -m bot
   ```

4. Открой бота в Telegram и нажми «Старт».

Бот должен работать постоянно, чтобы присылать напоминания. Для этого подойдёт любой небольшой сервер (VPS) или хостинг с поддержкой Python, например Railway или Render. Данные хранятся в SQLite в `data/bot.db`.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## Структура

```
bot/
  __main__.py        запуск, роутеры, фоновые напоминания
  db.py              SQLite: пользователи, пары, задачи, заметки, лекции
  schedule_parser.py разбор расписания из текста, CSV, Excel
  text_utils.py      разбор предмета и срока в задачах
  reminders.py       напоминания о парах и дедлайнах
  handlers/          обработчики команд и кнопок
tests/               тесты
```
